# AI RAG Assistant

🚀 **Full-stack RAG chatbot built with Angular 22 + FastAPI + Gemini**

Ask questions, upload PDF/Markdown/TXT documents, retrieve semantically relevant chunks, and generate grounded answers with visible source evidence.

### Highlights

- Angular 22 standalone architecture + Signals
- FastAPI REST API + CORS
- Gemini 3.8 Flash generation
- Gemini Embedding 2 vectors
- Chunking + overlap
- Cosine-similarity semantic search
- PDF / MD / TXT ingestion
- Source-aware responses
- Environment-based secrets
- Pytest + production Dockerfile
- Netlify + Render deployment ready

> Portfolio demo: this project intentionally uses a lightweight NumPy-backed vector index. For scale, swap in pgvector/Qdrant/Pinecone.
